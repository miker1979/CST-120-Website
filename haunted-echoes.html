Playable Release

Ghostline Chess

The first publicly released playable game project now housed beneath Haunted Echoes Studios.

Playable Windows Prototype

Ghostline Chess v1.0.0

A turn-based chess game developed in C# using Windows Forms and object-oriented programming.

Ghostline Chess began as a programming side project and became the first complete playable game released through the Ghostline organization.

Current Features

  • Complete 8 × 8 chessboard
  • Local two-player turn-based gameplay
  • Legal movement for standard chess pieces
  • Piece selection and highlighting
  • Capturing and blocked-path validation
  • Check, checkmate, and stalemate detection
  • New Game board reset
Windows 64-bit C# .NET Windows Forms
Download for Windows View Source Release Notes

Download the ZIP file, extract it, and run GhostlineChess.exe. Windows may display a SmartScreen warning because the prototype is currently unsigned.

Paranormal Project Direction

Investigation should create uncertainty.

Players should not receive the same clues, threats, locations, or ending every time they begin an investigation.

The project is being designed around incomplete information, conflicting accounts, supernatural deception, limited time, and decisions that alter what the group discovers.

1

Choose the Investigation

Players select from multiple haunted locations instead of visiting every site in one session.

2

Gather Connected Evidence

Clues, stories, objects, and supernatural events reveal different pieces of the mystery.

3

Survive the Deception

Possession, mimicry, and unreliable information make it difficult to know which characters or players can be trusted.

4

Shape the Ending

Evidence, location choices, survival, and group decisions determine the final confrontation and outcome.
