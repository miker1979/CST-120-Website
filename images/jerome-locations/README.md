# Jerome Location Image Guide

Use one folder per locked main location. Keep real-world reference photography and game-engine visualizations together so each website card can pair them reliably.

Recommended file names inside each location folder:

- `reference-01.jpg` — primary real-world photo used on the website
- `reference-02.jpg` — optional alternate reference angle
- `game-render-01.png` — primary in-game visualization matching `reference-01.jpg`
- `game-render-02.png` — optional alternate game visualization

## Image goals

- Photograph a recognizable exterior or interior angle that can be recreated in Unity.
- Prefer clean, level framing with enough architectural context to identify the location.
- Keep the real photo and game render at the same approximate crop and aspect ratio.
- Website comparison panels use a 4:3 desktop crop and a wider mobile crop.
- Preserve the actual architecture in the game visualization; change lighting, weather, props, supernatural effects, and atmosphere rather than redesigning the building.

If a source photograph is not your own, retain enough source information to add a photo credit before publishing it publicly.
