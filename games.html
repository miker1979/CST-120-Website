Playable Release

Ghostline Chess

Ghostline Chess is the first publicly released playable game developed under Ghostline Interactive Studios.

Playable Windows Prototype

Ghostline Chess v1.0.0

A turn-based chess game developed in C# using Windows Forms and object-oriented programming.

Ghostline Chess began as a programming side project and became the first complete playable game released by Ghostline Interactive Studios.

Current Features

  • Complete 8×8 chessboard
  • Local two-player turn-based gameplay
  • Legal movement for all standard chess pieces
  • Piece selection and highlighting
  • Capturing and blocked-path validation
  • Check, checkmate, and stalemate detection
  • New Game board reset

Platform: Windows 64-bit

Technology: C#, .NET, and Windows Forms

Status: Playable Prototype

Download for Windows View Source on GitHub View Release Notes

Download the ZIP file, extract it, and run GhostlineChess.exe. Visual Studio and a separate .NET installation are not required. Windows may display a SmartScreen warning because this prototype is currently unsigned.
